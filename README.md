# 🤖 ربات تبدیل متن به کد مورس

یک ربات تلگرام حرفه‌ای برای تبدیل متن به کد مورس و برعکس، با پشتیبانی از زبان فارسی و انگلیسی.

## 🚀 امکانات

- 🔤 تبدیل متن به کد مورس (پشتیبانی از فارسی، انگلیسی، اعداد و علائم)
- 📡 تبدیل کد مورس به متن
- 🎯 پشتیبانی از دکمه‌های شناور و کیبورد
- 📝 مدیریت پیام‌های طولانی
- ❌ قابلیت لغو عملیات
- 🔙 برگشت به منوی اصلی
- 🛡️ مدیریت خطاها و جلوگیری از Crash

## 📋 پیش‌نیازها

- Python 3.11
- یک توکن ربات تلگرام از [BotFather](https://t.me/botfather)

## 🔧 نصب و راه‌اندازی

### 1. دریافت توکن از BotFather

1. در تلگرام به [@BotFather](https://t.me/botfather) بروید.
2. دستور `/newbot` را ارسال کنید.
3. نام و یوزرنیم ربات را وارد کنید.
4. توکن دریافتی را ذخیره کنید.

### 2. اجرا روی سیستم محلی

```bash
# کلون کردن پروژه
git clone <repository-url>
cd project

# نصب وابستگی‌ها
pip install -r requirements.txt

# تنظیم متغیر محیطی
export BOT_TOKEN="توکن_دریافتی_از_BotFather"

# اجرای ربات
python bot.py
