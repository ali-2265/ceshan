# 🤖 Telegram Session Bot

ربات تلگرام برای ساخت و مدیریت سشن‌های تلگرام

## ✨ ویژگی‌ها

- ساخت سشن با شماره تلفن و کد تایید
- ذخیره سشن‌ها به فرمت .session
- ارسال پیام به پیام‌های ذخیره شده
- مشاهده لیست سشن‌ها
- پشتیبانی از پروکسی

## 🔧 پیش‌نیازها

- Python 3.11+
- اکانت تلگرام با API ID و API Hash

## 📦 نصب

```bash
pip install -r requirements.txt
python main.py
